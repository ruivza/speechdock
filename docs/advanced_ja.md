# プライバシーとキャッシュ

クラウド認識では音声を、クラウド読み上げではテキストを選択したサービスに送ります。字幕のクラウド翻訳は累積した文字起こしと最近の文脈を繰り返し送ります。ネイティブ認識はローカル対応を要求し、未対応言語はエラーにします。

履歴は最大 50 件の平文 JSON です。保存の停止と既存履歴の削除を選択できます。入力メソッドは履歴を保存しません。キャッシュ削除は API キー、履歴、保存済み音声、Apple 言語モデルを保持します。
