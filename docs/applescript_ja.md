# AppleScript の現在の動作

読み上げ、ファイル認識、翻訳、パネル表示の操作は現在の SpeechDock.sdef を参照してください。ファイルはアプリがアクセスできる範囲に制限されます。

`paste text` は互換性のため残っていますが、現在はクリップボードへのコピーのみ行います。別のアプリへの自動貼り付けはしません。直接入力には Voice Input を利用します。
