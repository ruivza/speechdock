# 开始使用

## 普通转录

1. 从菜单栏打开语音转文字面板，选择音频来源、识别语言和服务。
2. 麦克风来源需要麦克风权限；系统或指定应用音频需要屏幕与系统音频录制权限。
3. 开始录制，完成后停止。复制结果，在需要的应用中手动粘贴。

浮动麦克风按钮也会复制完成的文字。主程序使用沙盒，不通过辅助功能读写其他应用，也不模拟粘贴按键。

## Voice Input 语音输入法

1. 从菜单栏选择安装 Voice Input，按照目录选择提示安装到用户的 Input Methods 文件夹。
2. 根据系统提示注销后登录，在系统的输入源设置中添加 SpeechDock Voice Input。
3. 把光标放到可输入文字的目标中，切换到这个输入法。
4. 按 Control + Option + R 开始或完成识别，按 Esc 取消。

输入法通过 InputMethodKit 提交文字，使用本地原生识别。切换目标、移动光标、键入其他内容或进入安全输入会取消当前识别，避免把结果发送到错误位置。输入法转录不保存为历史。

输入法与主程序是两个独立应用，麦克风和语音识别权限、界面语言设置需要分别确认。输入法语言设置更改后通常需要注销再登录。

## 朗读、OCR 和字幕

把文字粘贴、输入或拖入朗读面板，选择声音后播放；保存音频时由用户选择位置。OCR 由用户选择屏幕区域，识别结果先放入面板供编辑。字幕随转录显示，可选择翻译服务；云端处理范围见 [隐私说明](advanced.md)。

## 设置与退出

外观设置提供界面语言和缓存清理；识别设置提供历史保存开关。通过菜单中的“退出 SpeechDock”完全退出。关闭面板不会结束菜单栏程序；开发时也可在 Xcode 点 Stop。
