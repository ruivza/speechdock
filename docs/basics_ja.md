# 基本操作

音声認識パネルで音声ソースとサービスを選び、録音後に結果をコピーします。Voice Input は InputMethodKit を使い、選択した入力先へ認識結果を送ります。通常のパネルはキー操作を模擬しません。

読み上げは貼り付け・入力したテキストを使用します。OCR はユーザーが選択した画面領域を認識し、読み上げパネルで編集できます。
